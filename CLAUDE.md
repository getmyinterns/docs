# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

This repo contains two distinct things:

1. **Docusaurus monorepo source** (root) — the open-source Docusaurus framework itself (packages, website, tests). This is upstream Docusaurus code.
2. **`gmi-docs/`** — a standalone Docusaurus 3 site for [GetMyInterns](https://help.getmyinterns.org), the actual GMI product. This is the primary work target.

`gmi-docs` is **not** a workspace in the root monorepo — it has its own `yarn.lock` and `node_modules`. Always `cd gmi-docs` before running its commands.

## gmi-docs Commands

```bash
cd gmi-docs
yarn start        # Dev server with hot reload
yarn build        # Production build
yarn serve        # Serve the production build locally
yarn typecheck    # TypeScript validation
yarn clear        # Clear Docusaurus cache (use when build behaves unexpectedly)
```

## gmi-docs Architecture

**Site config:** [gmi-docs/docusaurus.config.ts](gmi-docs/docusaurus.config.ts) — title "GetMyInterns", deployed to `https://help.getmyinterns.org`, uses `@docusaurus/preset-classic` with no custom plugins.

**Sidebar:** [gmi-docs/sidebars.ts](gmi-docs/sidebars.ts) — fully autogenerated from the filesystem. Sidebar order is controlled by `sidebar_position` frontmatter in `.md` files and `_category_.json` files in directories.

**Docs are organized by user type** under [gmi-docs/docs/](gmi-docs/docs/):
- `students/` — getting started, internships, interviews, time tracking
- `school-admins/` — platform administration (users, timesheets, reports, settings)
- `internship-providers/` — managing internships, interviews, timesheets/evaluations

Each section has an `images/` subdirectory with UI screenshots.

**Custom styles:** [gmi-docs/src/css/custom.css](gmi-docs/src/css/custom.css) — primary brand color `#2e8555`.

## Docusaurus Monorepo Commands (root)

Only relevant if working on the Docusaurus framework itself (not gmi-docs):

```bash
yarn build:packages   # Build all packages
yarn start:website    # Dev server for docusaurus.io
yarn test             # Jest (uses SWC)
yarn lint             # ESLint + StyleLint + CSpell
yarn lint:js:fix      # Auto-fix JS/TS lint issues
yarn format           # Prettier write
yarn watch            # Incremental rebuild on file changes
```
